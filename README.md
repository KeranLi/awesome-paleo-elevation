# Awesome Paleo-Elevation [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated reading list of paleo-elevation, paleoaltimetry and paleotopography research.

古高程、古地形与抬升历史研究文章库，面向地球科学研究者建立。这个仓库采用 `awesome-xxx` 的轻量形式：以一个人工维护的 Markdown 清单为核心，收录文章、地点、时代、方法和结论；PDF 由读者自行下载和阅读，仓库不代存论文全文。

## Contents

- [文章总表](papers.md)：本项目的主入口，手动维护。
- [按月更新](updates/)：检索记录、研究进展和主题综述。
- [阅读卡片](notes/)：读完文章后可补充的详细笔记，未阅读文章不会伪造结论。
- [引用文件](references/)：可选的 RIS / BibTeX 文件，便于导入 Zotero、EndNote 或 LaTeX。
- [结构化索引](catalog/papers.csv)：辅助筛选，不替代 `papers.md`。

## Scope

收录以下内容：

- 直接估算古高程或古地形的研究；
- 古高程代理的现代校准、验证和误差评估；
- 青藏高原、喜马拉雅及其他造山带的抬升、剥露和古排水重建；
- 明确讨论古高程结果与气候、生态、资源或地貌演化关系的研究。

不收录与古高程没有直接关系的一般现代海拔、气候变化或地形研究。

## How To Use This List

1. 从 `papers.md` 选择文章。
2. 自行从 DOI、期刊网站或机构数据库下载 PDF。
3. 阅读后补充地点、时代、方法、结论、限制和数据链接。
4. 对争议结论保留原文表述，并注明证据类型，不把单篇论文写成领域共识。

## Contributing

欢迎提交 Pull Request。每篇文章请在 `papers.md` 中补充以下字段：

```markdown
### Article title

- **文章**：作者（年份）。期刊。DOI。
- **地点**：研究区。
- **时代**：地质时代、沉积年龄或研究时间窗。
- **方法**：代理、测年、模型和关键校准。
- **结论**：作者的主要结论；若尚未阅读全文，写“待阅读”。
- **状态**：`to-read` / `reading` / `read`。
```

请保持一篇文章一个条目，使用 DOI 去重；不要提交受版权保护的 PDF。中文论文、学位论文和数据集可以收录，但请注明来源和访问日期。

## Data And Citation Files

书目元数据目前主要由 CrossRef 核验，`catalog/papers.csv` 和 `references/` 仅用于辅助管理。它们可能缺少摘要、页码或开放获取链接；最终判断以原文为准。
